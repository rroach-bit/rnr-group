# RNR Group of Companies

**Island Built · Tech Driven**

Official website for RNR Group of Companies — a Caribbean conglomerate headquartered in the Cayman Islands.

## Brands

1. **RNR Build** — Construction & Development
2. **CaySport360** — Sports News & Coverage
3. **Vibeworks Media** — Social Media Marketing
4. **RNR Cricket & Sports Equipment** — Premium Sporting Goods
5. **RNR Events** — Event Execution & Management

## Tech Stack

- HTML / CSS / JavaScript
- Bebas Neue + Outfit + Space Mono typography
- CSS animations with Intersection Observer scroll reveals
- Single-file deployment (no build step required)

## Deployment

The site is a single `index.html` file. Deploy to any static host:

- **Vercel**: `vercel deploy`
- **GitHub Pages**: Enable in repo Settings → Pages → Source: main branch
- **Netlify**: Drag and drop the file
